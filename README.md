My honest count of open browser tabs: **137** — one number, digits only.

Every one of them is a half-read article. I opened each one meaning to
finish it — a long read for later, a tutorial for a project I never started,
an essay someone swore would change how I think — and then I opened another
one. The count is not a flex. It is a confession: a reader who collects
openings and never gets to the endings.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt   # 137
```
